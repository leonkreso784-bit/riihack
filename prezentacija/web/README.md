# Prezentacija web (materijal za Leona)

Ovdje je sve za web verziju pitcha: `deck/` (trenutni deck, `index.html` plus slike i klipovi), `SKRIPTA.md` (pitch od 5 min) i `PREPORUKE.md` (savjeti, nije obavezno).
Otvori `deck/index.html` u Chromeu ili Safariju i pritisni bilo koju tipku prije promoa, da se zvuk smije pustiti.
Strelice mijenjaju slajd; promo (puna verzija) učitava se iz `../video/simpolis-promo-1080p.mp4`.
PDF rezerva je `prezentacija/Simpolis-pitch.pdf`.
Radi na kopiji i ne mijenjaj ono što već radi prije nastupa.
