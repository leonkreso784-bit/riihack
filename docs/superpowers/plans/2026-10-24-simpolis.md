# Simpolis: plan izvedbe

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** **Grad u simulaciji s pravom ekonomijom:** profesor napravi grad kao igru na Kahootu, studenti uđu kodom i
svaki vodi svoj hotel sa sobama; svi hoteli dijele iste turiste, sklapaju ugovore s gradskim tvrtkama i zarađuju
novac, pa odluka jednoga mijenja poslovanje drugih. AI glumi ljude u gradu i sudi po rubrici.

**Architecture:** Jedan Next.js 16 projekt (sučelje i `src/app/api/*`) iz Simonovog startera, Neon Postgres preko
Drizzlea, čisti TypeScript motor u `src/lib/engine/` koji računa sve brojke, i AI sloj u `src/lib/ai/` (Claude
preko AI SDK-a) koji vraća samo tekst i ispunjene kriterije. Sučelje radi na lažnim podacima dok rute ne prorade.

**Tech Stack:** Next.js 16.4 (App Router), React 19, TypeScript 5, Tailwind v4, shadcn/ui, Neon + Drizzle ORM, AI SDK
(`ai`, `@ai-sdk/anthropic`), Vitest, Vercel. Node 24, npm.

**Spec:** [ARHITEKTURA.md](../../../ARHITEKTURA.md) i [IDEJA.md](../../../IDEJA.md). Plan argumentira iz njih; tko izvodi
zadatak, čita oba.

**Pisano za:** Leona, Simona, Rina i njihove agente (Claude Code). Svaki zadatak ima GitHub issue istog ID-a.

## Global Constraints

- Sučelje i dokumenti na **hrvatskom**; kod, imena varijabli i datoteka na **engleskom**.
- **AI ne odlučuje o brojkama.** AI vraća tekst ili popis ispunjenih kriterija; kvalitetu i bodove računa `src/lib/engine/`.
- AI ključ (`ANTHROPIC_API_KEY`) i `DATABASE_URL` **samo na poslužitelju**; tajne samo u `.env.local` i na Vercelu.
- Modeli: lik `claude-haiku-5-5`; presuda i mentor `claude-sonnet-5-5`. Svaki AI poziv ima rok 20 s i rezervu.
- Pravila (vrijednosti u `src/lib/rules.ts`, zadatak L0): `MAX_ROUNDS = 4` (lipanj, srpanj, kolovoz, rujan),
  `SITUATIONS_PER_ROUND = 2`, `CLICK_QUALITY_CAP = 4`, `FALLBACK_QUALITY = 3`, `MISSED_QUALITY = 1`,
  `COPY_OVERLAP = 0.7`, `PASTE_SHARE = 0.5`, `MAX_STUDENT_MESSAGES = 6`, `MIN_OWN_ANSWER_CHARS = 20`,
  `MAX_OWN_ANSWER_CHARS = 2000`, `POLL_MS = 3000`, `METRIC_TOTAL = 250`, `JOIN_CODE_LENGTH = 6`,
  `PROF_CODE_LENGTH = 12`, `CODE_ALPHABET = "ABCDEFGHJKMNPQRSTUVWXYZ23456789"` (bez 0, O, 1, I, L).
  Ekonomija grada: `NIGHTS_PER_ROUND = 30`, `SEASON_DEMAND_BP = [6000, 8500, 9500, 5500]` (lipanj–rujan),
  `FIXED_COST_PER_ROOM = 300`, `STAFF_COST_PER_ROOM = 450`, `PRICE_MIN = 30`, `PRICE_MAX = 400`, `MARKETING_MAX = 5000`,
  `FINANCE_EFFECT_DIVISOR = 2000`, `FINANCE_EFFECT_CAP = 5`, `START_CASH = 20000` (sve u eurima).
  Osoblje: `STAFF_DEPARTMENT_LABELS` i `STAFF_SHIFT_LABELS` (oznake odjela i smjena na hrvatskom).
- **Profesorski kod nikad u adresi**; samo u httpOnly kolačiću `sp_prof`. Igrač u httpOnly kolačiću `sp_player`.
- Responsive: svaki ekran provjeren na **375 px, 768 px i 1440 px**; profesorova ploča čitljiva na projektoru.
- Izgled kao HotelixSim: Plus Jakarta Sans, kartice zaobljene 20 px, naglasak `#246bfd`, rast `#0f7a3c`, pad
  `#c42626`, upozorenje `#a16207`, pijesak `#f4e8d5`, menta `#d8f0ee`, podloga `#f5f8fd`. Boje samo kroz tokene.
- Svaki broj na ekranu ima ime i jedinicu (€, %, /100, „soba").
- Next.js 16 ima promjene u odnosu na ono što agenti znaju: prije pisanja koda pročitaj odgovarajući vodič u
  `node_modules/next/dist/docs/` (pravilo iz `AGENTS.md` startera). AI SDK: aktualna dokumentacija je u
  [ri-hack-4/docs/stack/ai-sdk-llms-full.md](https://github.com/leonkreso784-bit/ri-hack-4/blob/main/docs/stack/ai-sdk-llms-full.md).
- Iz HotelixSima se prenose **ideje, ne kod ni tekstovi**: sadržaj (hoteli, situacije) piše se iznova.
- Provjere prije svakog spajanja: `npm run typecheck && npm run lint && npm test && npm run build`.

## Review Focus

1. **AI ne odgovori, spor je ili nema ključa:** igra mora teći dalje. Presuda daje kvalitetu 3, lik kaže fiksnu
   rečenicu, a mentor ima fiksno pitanje i osvrt iz brojki. Test: S1 i S2 (model koji baca grešku → rezerva).
2. **Dvostruki odgovor** (dupli klik, dvije kartice): spremi se točno jedan odgovor, a drugi zahtjev dobije 409
   „Na ovu situaciju si već odgovorio". Test: L8 smoke korak „dupli odgovor".
3. **Krug se promijenio dok student piše:** odgovor na situaciju starog kruga dobije 409 „Ovaj krug je završio".
   Test: L8 smoke korak „stari krug".
4. **Student izgubi kolačić** (osvježi, drugi preglednik): ponovni ulaz s istim kodom, imenom i imenom hotela vraća
   **isti hotel**, ne novi. Test: L8 smoke korak „ponovni ulaz".
5. **Obračun mjeseca dvaput** (profesor dvaput klikne, ili rok i klik stignu u istoj sekundi): grad prijeđe u
   sljedeći krug jednom, a novac i noćenja obračunaju se točno jednom. Test: L8 smoke korak „dvostruki obračun".

## Kako radimo s više agenata

  `src/app/layout.tsx` i `src/app/globals.css` (Rino). Sve ovisnosti instaliraju se u L0; nova ovisnost = poruka Leonu.

  (smije sam sebi). CI (L0) mora biti zelen. Spajati često, barem svaka 2 sata.
- Svaki agent na početku čita: ovaj plan (samo svoj zadatak i Interfaces susjeda), [ARHITEKTURA.md](../../../ARHITEKTURA.md),
  `CLAUDE.md`, `AGENTS.md`.

- `financeEffect = clamp(trunc(profit / FINANCE_EFFECT_DIVISOR), −FINANCE_EFFECT_CAP, FINANCE_EFFECT_CAP)`.

različito raspoređenim snagama:

```text
g_i = (now_i − start_i) / (100 − start_i)   ako now_i ≥ start_i
g_i = (now_i − start_i) / start_i           ako now_i < start_i   (start_i = 0 → 0)
progress = round1(100 × Σ 0,2 × g_i)         raspon −100 do +100
```
